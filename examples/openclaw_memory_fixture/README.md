# OpenClaw Memory Fixture

This fixture is a tiny deterministic OpenClaw-style memory workspace for OC0
design tests.

It contains:

- `MEMORY.md`: one durable preference or decision.
- `memory/2026-06-19.md`: daily observations that later adapter work can map to
  `core`, `near_drift`, `far_coherent`, and `semantic_break` examples.

No runtime adapter, plugin, LLM call, or automatic durable write is included.
