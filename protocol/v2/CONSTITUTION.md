# Nollm V2 Constitution

Dream Geometry V2 is a local cellular atlas, not a strict algebraic scheme and not a global tree.

Core rules:

- Not an LLM.
- Architecture is the Index.
- Local chart first; global atlas later.
- Evidence is durable and auditable.
- Geometry is deterministic and separately verifiable.
- Cortex proposes semantics; Core validates and executes geometry.
- Gravity is internal to Core/Field and never an external recall selector.
- Adapters are thin and never define geometry.

V2 does not use external anchors as the recall entry. Query Probe is temporary, isomorphic to Dream Shard growth, and must fall back to exact Evidence. Coverage uses directed `K↑ / K↓` kernels.
