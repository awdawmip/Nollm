# Historical M1 Adversarial Reproductions

These scripts reproduce the withdrawn M1-C7/M1-C8 capability, callback-fence,
shadow-Store, and adversarial-call routes. They depend on the public API that
existed at that historical revision and are retained only as traceable reference
material.

They are not active validation tools. Current packages must not restore
capability, binder, writer-authority, compiler, or mutable Store exports merely
to make these scripts importable.
