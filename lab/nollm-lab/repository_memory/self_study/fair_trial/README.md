## 空间路径与小重叠边界

六名 Surface 首答者共进行 31 次候选浏览操作、选定 6 个入口并做了 6 次原生物理召回。60 个结果中 26 个来自入口本格，34 个经过两步；44 份语句都在第 0 层，相邻物理层没有可供一步返回的语句。9 个正确来源中有 7 个在本格，另 2 个由先上后下找到。

例如 Q04 从 `L0(-2,1)` 向上到 `L−1(-1,0)`，权重为 30,720，反向为 20,480；从这里再向下到 `L0(-1,0)`，权重为 27,989，反向为 38,229。路径连乘取整得到 13,119，`provenance.py` 排名第 8。该来源在这次召回中的胜出路径经过共享上层。核对使用原生返回的分数与核序列；若多个中间格均相容，诊断保留所有相容路径。

这六个入口在两步内共展开 311 条不同的有向边，14 条正向只命中 1–2 个采样点。实际进入前十的获胜路径使用 22 条不同的有向边，全部正反权重不同，全部有反向采样支持，且正向命中数均大于 2。另用预先已有的独立边界例核实，细格向上权重 683 时，对应粗格向下可以为 0，而 Surface 依然能沿登记的成员下钻。这个现象在独立例中确实存在；本轮三个实测漏项的可定位原因是前十截断和当前入口的两步范围。[逐入口和逐边记录](geometry.json)

## 这轮能回答什么

题目作者只读固定提交的 44 个 Core/Access Python 文件以及往期题面，用另一个上下文写出六道新工程题、12 个不同源码证据和 18 条作答要点。原实验分支先提交题目全文、答案钥匙的 SHA-256、物理场与实验工具的指纹，远端回读后才发放题目。18 个独立 Codex 首答会话各做一题一种方法，按题轮换三组分配顺序。每个答题者只收到自己的题目、命令入口和相同的提交格式。三组共用 44 份源码的 Git blob。全仓 903 条场的其他对象未参加这次比较。[预注册提交](https://github.com/awdawmip/Nollm/commit/9196e7fab6efe1d89dfdeaeeeaca4aa928f9eb5b)

每题的发现预算为 6,000 个可见 token，源码预算为 5,000 个，最多打开 3 个不同文件，答案连同行号引用至多 450 个 token。每次输出以 `o200k_base` 分词，重复阅读重复计量；不足的预算会截断可见内容。三组适用相同的上限，各自可以提前停止。搜索组在真实源码中选正则，看到路径、符号和行号后决定打开哪几份；平面组可分页浏览同一张含 44 份 AOCI 说明的表。Surface 组从观察阶 1 的实际候选页逐阶选一个物理入口，随后调用一次向上和向下的原生召回。允许两步、beam 64、最大跨层差 2、返回前 10 个句柄；侧向和 Bridge 预算为零。该组只能打开真实返回过的文件。AOCI 引用保留在说明内，传播由原有占用及覆盖核决定。

作答文本交给两名独立评阅者，移除组名、工具轨迹和会话编号，两人的答卷顺序不同。按冻结要点逐项判断，有分歧的项目按同一钥匙核定。引文另由程序对齐：文件、实际显示过的完整源码行、答题者标注的行号和预先冻结的证据区间必须有交集。完整成功要求三条要点全对、两份证据都落到实读引文、无实质矛盾且符合预算；有部分要点或证据则列作局部命中。表中“不相关”表示未列入该题冻结的证据集合。相关文件未被引到支持行、读了旁证、完全没有命中三者可以分别查到。

## 复算

需要含 `691590d` 的 Nollm Git checkout、Python、`tiktoken==0.14.0` 和可用的 `o200k_base` 词表。使用上一轮复算包的 `fields/fitted` 可直接复用原生场；以下命令也能从既有放置规则重建同一场。`verify` 会逐会话重放已封存的选择、核对每条可见输出的字节指纹并重新计数。重放无需再次调用模型，历史首答和判分保留在固定样本中。

```sh
D=lab/nollm-lab/repository_memory/self_study
F="$D/fair_trial"
O=$(mktemp -d)
python "$D/fit_layout.py" --repo . --field "$O/field"
python "$F/replay.py" verify --fixture "$F/observations.json" --repo . --field "$O/field" --emit-traces "$O/traces"
python "$F/score.py" --sessions "$O/traces" --gold "$F/key.json" --judgments "$F/judgments.json" --out "$O/score.json"
python "$F/audit_geometry.py" --field "$O/field" --sessions "$O/traces" --gold "$F/key.json" --out "$O/geometry.json"
```

将重新生成的两份 JSON 分别与本目录的 `scorecard.json`、`geometry.json` 逐字节比较即可验证。答案钥匙在全部首答后公开，其 SHA-256 与事前冻结值相同。[冻结协议](freeze.json) · [公开的评分钥匙](key.json)
