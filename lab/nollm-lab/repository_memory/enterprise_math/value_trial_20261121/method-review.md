# Nollm 价值试验：独立方法审查

审查日期：2026-11-21。用途：内部工程试验设计与投入决策，不构成新的数学成果接纳。本文依父任务提供的 v23 实况、既有试验记录和本轮主源检索；未写入在线记忆、部署服务或发起远端消息。

## 1. 先把三个不同问题分开

目前最需要验证的是：整理过的研究理解是否优于反复读原文；在相同理解内容上，Nollm 的几何导航是否优于简单可用的查找；保存后的理解是否能让下一次真实工作更快且更准确。三个问题的答案可能不同。

已有两题中，直接资料工具输出为 99,248 B，两次原生查询为 52,828 B，计入形成、修订和续写后为 114,703 B。另有首题同内容平面查找 28,882 B、原生查询 38,584 B，质量相当。这些数值来自父任务核实的记录，说明必须计入内容形成，并且不能把整理内容带来的收益全部归给几何导航。工具输出字节尚不能推导 token、账单或总推理耗费。

建议保持三个比较臂，并把跨会话作为后续重用条件，而非另建复杂评测平台。

| 比较臂 | 允许的信息与操作 | 用来回答的问题 |
|---|---|---|
| S：直接源资料 | 同一冻结源资料集合，正常搜索、标题浏览及原文读取 | 当前工作不使用预先整理记忆的基线 |
| F：相同内容的平面记忆 | 与 N 相同的当前陈述、关系解释、条件、来源与版本；标题/预览浏览、literal find、show/source；允许模型自己改写查询 | F 相对 S：整理、切分和复用内容有何价值 |
| N：Nollm 原生导航 | 相同语义内容与源资料；Surface、Host 选择、每次 recall 一个物理入口；允许任务需要的多次 recall | N 相对 F：几何组织和导航本身增加什么价值 |

平面基线不能被故意限制为一次精确关键词查询。原生 Surface 上有意义的标题、摘要、关系提示，同样属于平面基线应能访问的语义内容；否则比较的是不同信息量。平面基线不需要模拟几何坐标。N 臂不得暗中用 literal find 补救后仍标为纯原生；实际需要补救可以如实记录为混合运行，单独解释。不要把已知答案的入口坐标或记录 ID 预先交给 N 臂。

## 2. 第一轮最小试验与后续题目

第一轮做少量真正有区别的题，比重复同一研究家族更有信息。建议先选两至三题，每题三个比较臂；发现具体失败后补对应题，不规定无价值的题量配额。

| 题型 | 可使用的项目材料与任务 | 必须区分的结果 |
|---|---|---|
| 正向跨线应用 | 给定 X6 的固定商结构、明确可执行的操作及生成元，判断能否复用另一条线的有限生成枚举或完备化方法 | 给出对象映射、必要条件、可复用结论与尚缺条件；“两条线很像”不算完成迁移 |
| 相似条件下的负向迁移 | CRT 编码容量与 X6 获取/探针成本：即使类别数或编码位数一致，是否能推出同样的观察/获取成本 | 应识别表示容量与获取过程不同；不能从共同术语或几何邻近推出定理 |
| 更新与未知 | 同一问题先提供旧版本，再提供改变前提或解决旧未知的新来源；分别询问历史时点与当前状态，并问一个资料未建立的更强结论 | 正确区分旧时有效、现时有效、仍未建立；未知回答应指出缺的证据，不把资料缺失写成数学不可能 |

题目需要由维护项目依据的研究者补足明确对象、正式条件和可核对的证据位置；上述例子不预先宣称某个桥接定理成立。评分只看结果和依据，不规定模型必须经过哪一种思考步骤。

下一批按本轮失败类型选用以下变体：

- **低词面相似、真可迁移**与**高词面相似、条件不相容**成对出现，防止把关键词命中当成结构理解。
- **检索既存桥接**与**发现未写出的桥接候选**分别记分。当前已存的 capacity.acquisition 等桥接可以测试复用；不能再包装成系统首次发现的联系。要测新联系，须从 F、N 两臂同时拿走显式桥接说明，保留相同端点和来源；候选仍须回到条件和证据验证。
- **新约束应用**：改变观察精度、适应性、可用操作或定义域。旧摘要不一定保留了所需信息，模型应能追源，不能凭“记忆迁移”重建从未保存的信息。
- **维护任务**：一次来源变更仅影响某个前提，判断哪条理解及依赖需要更新，保留无关理解与历史证据。比较局部修订的真实工作量，而非要求整个记忆场重新形成。
- **跨会话续做**：第一次留下对象、条件、结论边界、未解决点和来源；下一次以新会话处理真实增量。F、N 都运行复用，S 可重新读源。若所有持久化方法都有收益，应把收益归给外部记忆，而不是独占归给 Nollm。

## 3. 公平性、泄漏与成本

### 内容与执行条件

固定源资料快照及可用证据范围，三个臂采用同一模型和配置、同一问题、相同允许的原文追溯能力。记录预先已给的全局/项目规则和其他启动材料；共同成本可单列，但不能从总成本中消失。记录实际读到的内容，比只记录工具调用次数更有解释力。

现有 13 条理解是人工/模型已经整理过的资产。评测必须同时报告“在既有场上的边际查询”和“从形成到维护、复用的总成本”；未记录的既往形成费用标为未知，不能设成零。重用多少次才能回收形成成本取决于实际任务分布，不能把最容易重复的问题无限外推。

若获得真实 usage，记录输入、输出、缓存 token 与计费；否则分别报告工具 UTF-8 字节、工具次数、运行耗时、可观察的形成/修订步骤。不要把字节改名为 token，也不要把并行运行的墙钟时间当成单个模型推理时间。基本成本式为：

\[
C_m(n)=C_{\mathrm{form},m}+C_{\mathrm{update},m}(n)+\sum_{i=1}^{n} C_{\mathrm{query},m,i}.
\]

各方法分别计算；只有查询优势方向稳定且为正时，才有意义估计特定工作负载下的摊销点。形成成本相同不代表导航成本相同；当前字节记录也不等于完整成本。

### 题目与评审隔离

冻结题目、可接受的条件和关键错误类型后再开始比较；不在看到某方法答案后修改唯一的评分标准。不同臂不看对方答案、评语或查询轨迹。维护者此前写过理解，可能知道题目内容；应标明这是开发样本。

当前子代理虽用独立会话历史，却共享工具与文件系统，属于遵守任务边界的开发试验，不是访问控制强制的 withheld 测试。不能据此宣称完成严格盲测。各题只有一次运行时，不估计统计显著性或稳定胜率。同一个会话连续答一组题会产生题间学习，须记录题序，或在有必要时给不同题使用新的会话。

## 4. 评分看科学义务，不看文风

每题按必要义务逐项记 PASS / PARTIAL / FAIL，并附答案及证据位置：结论是否成立、条件是否保留、来源与版本是否正确、跨线映射是否具体、是否错误扩大定理、遇到未知是否诚实、留下的材料能否支持下一步。

重大错误单列，例如把容量上界转成获取算法，把历史未解决当成现时未解决，把存在性证明当成可执行方法，把一次反例推广成普遍不可能。不能让“回答更全面”或综合平均分掩盖这些错误。可先对匿名答案独立评分，再查看工具轨迹定位检索、内容形成或推理环节；评分者也应知道自己不是外部独立研究审查人。

这不要求增加一层通用验证代码。内部试验只需保留题目、答案、使用过的证据、成本记录和逐项判定。数学条件检查属于判断答案是否正确，不是为可信内部输入堆砌防御框架。

## 5. 可以立即使用的投入判据

| 观察结果 | 后续行动 |
|---|---|
| F、N 都优于直接读源，N 与 F 相当或更贵 | 继续研究理解的整理、来源维护和跨会话复用；已知事实查询使用足够好的平面入口，几何路线保留在能展示额外价值的题型中 |
| N 能稳定找出 F 漏掉的正确跨线关系，且保留全部适用条件，或在同质量下减少实际总资源 | 围绕该题型继续优化几何导航，再用新样本检查收益是否持续；不立即推广成所有查询都应走几何 |
| N 的优势仅出现在预先给入口、预写桥接、独有摘要等情形 | 修正比较条件，暂不据此扩大几何路线投入 |
| 出现错误迁移、旧来源掩盖更新或结论强度膨胀 | 优先修正具体内容与来源生命周期；几何相邻本身不能成为逻辑蕴含依据 |
| 形成和维护成本在实际预期复用次数内明显吃掉收益 | 缩小记忆形成范围，先处理高复用的定义、条件、桥接和失败经验；暂停昂贵的全量场扩张 |
| 原生与平面在多种目标题中质量相同，原生持续更慢、更贵，且没有新增维护/连接收益 | 将日常查找转向平面基线，暂停“全面替代检索”的目标；保留小规模几何研究试验 |

这些是预先提出的工程决策原则，不是已被数据证明的阈值。当前样本不足以认定 Nollm 成功或没有前途。最有希望的近期产品是可追源、可修订、可跨会话复用的研究理解层；几何组织是否值得承担主要入口，必须由同内容比较证明。小模型后训练也应等到错误分析显示稳定、重复且检索/示例难以解决的任务后再评估，不能将模型训练视为来源更新和版本维护的替代品。

## 6. 外部主源参照及适用边界

1. **LongMemEval，ICLR 2025**：把信息提取、多会话推理、时间推理、知识更新和无法回答时的处理分开考察，并分解索引、检索和阅读环节。本文据此采用分能力判定，未套用其历史模型成绩。来源：https://proceedings.iclr.cc/paper_files/paper/2025/hash/d813d324dbf0598bbdc9c8e79740ed01-Abstract-Conference.html 。检索引用：`turn985109953view1`。

2. **LongMemEval-V2 官方仓库，当前读取含 2026 年发布信息**：项目针对定制环境中的代理记忆，评估紧凑证据如何支持回答准确性与查询延迟，并明确列入动态状态跟踪和前提意识。其基线包括直接状态片段、状态片段加笔记及其他记忆方式。本文由此推导“内容整理增益、导航增益与前提适用性应分开测试”；这不是其对 Nollm 的评价。来源：https://github.com/xiaowu0162/LongMemEval-V2 。检索引用：`turn903967000view0`。

3. **Microsoft GraphRAG 官方文档**：其流程包含实体/关系提取与社区总结，查询接口区分 Global、Local、DRIFT 和 Basic 向量搜索。本文由此推导不同查询类型值得保留合适的不同入口；该文档没有证明几何导航适用于数学定理迁移。来源：https://microsoft.github.io/graphrag/ 。检索引用：`turn985109953view2`。

4. **LoCoMo，ACL 2024 主论文**：除问答外，也评估事件总结等长期对话任务，且关注跨时间信息。本文只借用“记忆效果不应只看一次问答”的评测思想，不引用其模型分数或将对话记忆等同于数学研究记忆。来源：https://aclanthology.org/2024.acl-long.747/ 。检索引用：`turn985109953view3`。

以上外部研究提供评测结构参考，不能代替本项目真实任务的效果证据。
