# Not An LLM

Nollm is not an LLM. It does not generate text, plan actions, reason independently, or maintain hidden state.

Nollm exists because LLMs need a memory surface that is external, durable, inspectable, and modest. The notebook gives a model something to read and write without pretending to be the model.

Core remains dumb. Cortex may be smart, but Cortex is not the source of truth.
