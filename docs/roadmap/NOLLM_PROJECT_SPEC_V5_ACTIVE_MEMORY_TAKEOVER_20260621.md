# Nollm Project Spec V5: Active Memory Takeover

Raw records are archived. Nollm is what remembers.

OpenClaw runs the conversation. Nollm owns active memory.

V5 replaces the OpenClaw memory-file companion route as the main project direction. `MEMORY.md`, `memory/*.md`, and `DREAMS.md` become archive/provenance inputs after migration, not active recall sources.

MT1 is limited to Archive Ingest & Cutover Foundation. It does not change runtime memory injection or shut down legacy paths.
