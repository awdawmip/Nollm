# D-Series Status

D1-D9 are implemented as reference/protocol-side Dream Geometry modules.

They are not yet the stable V1 external recall/tool surface.

- D1 polygon overlap is allowed only inside the pure geometry kernel.
- D4 placement candidates are candidates, not automatic card placement.
- D5 coarse emergence candidates are candidates, not confirmed memory.
- D6 scale scan traversal is deterministic traversal planning, not autonomous recall.
- D7 OpenClaw dream experiment is a fixture, not a production integration.
- D8 parameter experiments are diagnostics, not final parameter lock.
- D9 keeps audit/history as support organs, not the project center.

Stable Core remains filesystem-first, explicit, ledgered, and auditable. Dream
Geometry records are experimental primitives unless a later task explicitly
promotes a surface.
