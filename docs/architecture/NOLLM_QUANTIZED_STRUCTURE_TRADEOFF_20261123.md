## 1. 研究问题与结论

用户本轮允许低精度造成的缺项保留为实际关系结构，询问在一定结构差异比例下的最佳计算成本。目标是单次有限精度运算产生可回放的关系；精确几何只在离线评价中作为参照。

当前 Python Lab 中，**10–12 个二进小数位是平衡区；选择 12 位作为显式量化模式默认值，8 位作为接受约百分之一结构差异的速度档**。这不是整数总字宽，也不是最终输出 Q16 的精度。

五轮交错计时中，复用几何核时 12 位比 8 位的中位成本仅高 5.16% / 3.95%，主组与第二组的结构差异分别从 1.051% / 1.305% 降为 0.1318% / 0.1312%；有需求格的平均显示压力偏差从 0.543 / 0.472 分降为 0.029 / 0.026 分。一次性调用每格重编译时，10 位也是合理选择。6 位把结构差异提高到约 5%，进一步节省的时间较有限。

这里的默认选择是本次成本与质量权衡，不是对所有硬件或数据的最优定理。主要收益来自省去区间认证、精度提升与精确回退；8–24 位之间的 Python 整数执行成本形成较平的平台。有限数据中观测到零差异，也不意味着对所有临界输入零差异。

## 2. 单次定点合同

新增 `mode="quantized"` 与 `fractional_bits=p`，接入覆盖、支撑压力及候选比较。输出标明 `lab_quantized_rational_axial_quadrature_v1`、`quantized_sample_share` 与具体小数位。对选定量化标签的命中份额仍为精确的 `hits/96`，材料分配及压力也按这些份额精确计算。

`quantized_rational_kernel.py` 的非线性执行顺序固定：

1. 精确消去相同的有序外层扭转后缀和共同世界锚。
2. 源仿射使用精确整数系数得到比值，再将坐标取为 `2^-p` 的整数倍；扭转中心在重锚后一次舍入。
3. 范数、半径归一化、二次截止函数、扭转参数和旋转行按照声明顺序运算，每个保留中间量使用 signed half-even。范数和旋转行采用融合整数乘加后舍入。
4. 目标逆仿射使用精确整数系数，结果舍入到同一精度，再直接决定格归属。

运行时不建立误差盒、不进行归属认证、不提高精度、不调用完整 Fraction 映射修正。共同扭转消去后只剩仿射的情况继续复用原精确整数核；这里本来已经是廉价整数计算。

`p` 是保留的二进小数位。参数仍以有理数输入，整数格地址和临时乘积保留所需整数长度。正作用半径和强度通过精确整数比值参与后再舍入；极小正半径不会因参数存储先变成零分母。

相同输入、位数和执行顺序产生相同关系。这是一种确定性的有限分辨率规则；空间位置和变换参数决定哪些弱关系消失、哪些关系出现。只有算术递推产生的变化被保留，没有为凑出错误比例额外随机删边。

## 3. 评价单位

对一个源格，记精确参照的 96 个目标标签为 `labels_ref`，量化标签为 `labels_p`，命中直方图为 `n(c)` 与 `n_p(c)`。有命中的有向源—目标对构成关系集合 `E_ref` 与 `E_p`。不同映射场景单独计数。

| 指标 | 定义与用途 |
|---|---|
| 样本标签变化 | 不同标签数 / 全部样本数，观察归属变化 |
| 关系漏失率 | `|E_ref − E_p| / |E_ref|`，观察原关系消失 |
| 关系误增率 | `|E_p − E_ref| / |E_p|`，观察新关系中参照不存在的部分 |
| 总结构差异 | `|E_ref △ E_p| / |E_ref ∪ E_p|`，即 Jaccard 距离 |
| 份额 TV | 每源 `sum_c |n(c)−n_p(c)| / 192`，观察分配质量变化 |
| 完整漏失质量 | 完全消失关系原有的 `n(c)/96`；与一般份额移动分开 |
| 压力变化 | 相同材料与需求下，显示压力的 MAE、p95、最大差值；有需求格单列 |
| 候选次序变化 | 相同候选集合按同一目标排序，平手单列，记录改变后实际代价 |

单个样本占一个源格的 `1/96`。只含一个命中的关系可能因一次归属变化整个消失，因此关系漏失率与质量漏失率不能互相替代。一次源格的 96 个样本是整体几何计算，统计时也不将它们假定为独立随机试验。

对固定材料量 `m(d)`，记每个源格的份额 TV 为 `TV_d`，则单个目标支撑偏差满足：

\[
|\Delta S(c)|\le \sum_d m(d)TV_d.
\]

固定需求 `D(c)` 和 `κ` 时，原压力函数给出：

\[
|\Delta P(c)|\le \frac{99}{D(c)+\kappa}\sum_d m(d)TV_d.
\]

这些是离线解释量，没有作为在线修正条件。最终召回还受入口、beam 与排序影响；本实验以关系、份额及压力的实测结果作选择依据。

## 7. 如何选精度

建议按实际可接受的差异选静态配置：

| 任务取舍 | 建议 p | 本次两组结果 |
|---|---:|---|
| 明确接受约 1%–1.5% 的关系差异 | 8 | E=1.051% / 1.305%；完全漏失份额约 0.03%–0.04% |
| 两组实测均要求 E≤0.3%，或较重视每格重编译成本 | 10 | E=0.2635% / 0.2625% |
| 通常复用几何核，兼顾压力与候选稳定性 | **12，量化模式默认** | E≈0.13%；压力 MAE≈0.03 分 |
| 本次 E≤0.1% | 16 | 两组主场景边集合未变，第二组仍有一个标签变化 |
| 本次主场景标签也一致 | 24 | 主场景中观测到一致；临界探针仍可缺项 |

严格 1% 的容忍线不能用 p8 两组结果声称满足；两组都测过的档位中，p10 是满足 0.3% 的最低档，p12 是满足 0.15% 的最低档。第二组没有全扫 p7/p9/p11/p13/p14/p15，因此这些结论不将未测档位排除为可能更优。

p6 比 p8 的复用中位成本仅少 2.43% / 12.36%，结构差异却增至 4.987% / 5.210%，压力 MAE 增至 1.582 / 1.314 分。因此本次不选择 p6 为默认。

用户可以把量化关系直接视为场的工作结构。实测显示低精度主要改变边界附近的弱覆盖关系；这说明其质量成本可能小于边数量成本，却尚不证明它会提高语义召回。若“维持一定比例”指精确控制一个非零错误率，固定 p 本身没有这个保证；本次目标是接受自然出现的差异，并离线选择成本合适的分辨率。

调用方式：

```python
coverage = sampled_rational_coverage(
    source, target_layer, source_map, target_map,
    mode="quantized",       # 默认 fractional_bits=12
)
rougher = sampled_rational_coverage(
    source, target_layer, source_map, target_map,

```

`evaluate_rational_pressure` 与 `compare_rational_pressure` 接受同样的模式与参数。它们依选定标签计算支撑、压力和候选变化，运行时不拿精确参照替换关系。

固定精度不会跨所有任意有理变换维持同一个错误比例。这里比较的是明示输入上的实际结构差异。可以将可接受比例 `eta` 作为成本选择条件：

\[
p^*\in\arg\min_p C(p)\quad\text{满足实测 }E_{\rm structure}(p)\le\eta.
\]

这个条件只用于离线选择配置；运行时仍接受该精度直接给出的关系。若两个档位的时间差处于计时波动范围，应同时观察质量与独立输入表现。

## 方法与运行时来源

- [Python 3.12 `sys.int_info`](https://docs.python.org/3.12/library/sys.html#sys.int_info)：整数内部以 `2**bits_per_digit` 为基数存储。本机为 CPython 3.12.14、30 位一组、每组 4 字节；小数位数不是内存字宽，较少小数位的时间收益需测量。
- [Croci 等，Stochastic Rounding: Implementation, Error Analysis, and Applications](https://eprints.maths.manchester.ac.uk/2843/1/cfhm22.pdf)：区分重复得到同一结果的最近值舍入与概率舍入。本轮使用确定性半偶舍入。
- [前轮自适应执行](NOLLM_ADAPTIVE_RATIONAL_EXECUTION_20261122.md)与[覆盖精度预算](NOLLM_COVERAGE_PRECISION_BUDGET_20261122.md)：提供精确参照、原采样合同和有限精度边界。
