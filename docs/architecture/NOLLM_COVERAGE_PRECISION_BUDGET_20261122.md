# Nollm 覆盖关系的最低精度与误差预算

日期：2026-11-22。对象：当前 Q40 Core 与显式有理数 Lab 的最终目标轴向坐标、96 点覆盖份额和支撑压力。

## 1. 当前可采用的结论

允许坐标有误差时，可以降低精度而保持离散覆盖关系。所需位数由样本到目标格边界的距离决定，不能只按“有理数”或“浮点数”的类型决定。

对现行 Core，若要求在**所有合法可写源格**上保持目标集合，采用**最终目标坐标统一 half-even 降位、沿用原 nearest/tie 规则、没有精确回退**的模型，最低非负固定二进小数位是 **40**。整数同余构造得到 3 个合法源格见证，覆盖全部 p=0…39：每档至少有一例目标集合改变；p=40 对原 Q40 坐标恒等。第 3.4 节给出可复现证明。这是指定模型的最坏情况结论，不限制带自适应判定的实现。

另一个有限 Core 探针覆盖 **1,034 个案例、99,264 个样本**，对最终目标坐标扫描 0–40 个二进小数位：

- 从 **10 位**到 40 位，本次样本的覆盖目标集合都相同。
- 从 **14 位**到 40 位，本次样本的逐点标签、命中计数和覆盖目标集合都相同。
- 利用本次全部样本的最小边界裕量，**15 位**满足统一的严格误差证书。
- **16 个二进小数位可作为局部残差计算的工程起点**。用可信总误差界检查边界，无法认证的点保留精确判定。这是建议的执行策略，不是把 16 位声明为所有合法变换和所有地址的最低位数。

探针先完成原来的精确计算，再量化最终坐标。它测量精度需求，没有测量端到端提速，也没有修改当前 Core 的默认精度。新有理数家族的补充结果见第 4 节。

## 2. 先区分要保持的对象

| 目标 | 实际要求 | 与精度的关系 |
|---|---|---|
| 每个样本归属相同 | 96 个带位置标签的样本分别落入同一格 | 最强的本轮离散要求 |
| 命中计数相同 | 每个目标的样本数相同 | 样本可以交换目标后互相抵消 |
| 覆盖目标集合相同 | 哪些目标至少有一次命中相同 | 计数可以变化而集合不变 |
| 份额误差在预算内 | 比较 `hits/96` 的绝对差、TV 等明确指标 | 容差必须说明衡量方式 |
| 压力或显示分数相同 | 当前材料加权后得到相同压力或显示整数 | 还依赖材料量、需求量和舍入门槛 |
| 连续几何覆盖相同 | 连续区域的交叠、面积或拓扑相同 | 96 点采样本身不提供这个保证 |

全部样本标签相同，会使计数、目标集合和当前库存下的精确压力相同。反向推断不成立。当前 Core 的 `MIN_HIT_COUNT=1`；有理数 Lab 也保留全部正命中目标。因此即使只移动一个样本，也可能新增或删除一条离散覆盖关系。

“允许误差”不能省略对象。例如，允许坐标误差为一个格距的万分之一，不意味着边缘覆盖关系一定保持；允许份额误差 1%，也不意味着一个仅有单样本支撑的关系一定存在。

### 3.3 用本次最小裕量给出保证

全部样本没有精确落在格子面上的点。其最小正投影裕量为

\[
\mu_{\min}=\frac{63\,050\,232}{2^{40}}.
\]

若每轴最终坐标误差不超过 \(\varepsilon=2^{-(p+1)}\)，统一采用保守条件 \(3\varepsilon<\mu_{\min}\)，则 p=15 满足，p=14 不满足该统一证书。

这解释了实测与保证的差别：p=14 的实际舍入方向没有使本批样本越界；p=15 则保证任意满足相应误差上界的方向都不会让这些样本越界。16 位留出一位额外空间，适合作为后续带边界回退的起始选择。

## 5. 可实现的边界证书

### 5.1 三组线性面

设目标格整数中心为 \((a,b)\)，点到中心的轴向位移为 \(u=q-a, v=r-b\)。在度量 \(N(q,r)=q^2+qr+r^2\) 下，该格的 Voronoi 六边形是

\[
|2u+v|\le1,\qquad |u+2v|\le1,\qquad |u-v|\le1.
\]

这三个线性式分别对应三对相邻格的距离比较。定义面裕量

\[
m_1=1-|2u+v|,\quad m_2=1-|u+2v|,\quad m_3=1-|u-v|.
\]

若可信坐标误差满足 \(|\Delta q|\le\varepsilon_q\)、\(|\Delta r|\le\varepsilon_r\)，则下列条件保证整个误差矩形严格处在同一格内：

\[
m_1>2\varepsilon_q+\varepsilon_r,\qquad
m_2>\varepsilon_q+2\varepsilon_r,\qquad
m_3>\varepsilon_q+\varepsilon_r.
\]

认证可以围绕精确参考点计算，也可以围绕低精度近似点计算；后一种用法必须先有相对于真实目标坐标的可信总误差界。误差界不能仅凭所用数据类型自行假定。

### 5.2 公共分母整数判定

若 \((q,r)=(Q/D,R/D)\)，令

\[
U=Q-aD,\quad V=R-bD,
\]

\[
M_1=D-|2U+V|,\quad M_2=D-|U+2V|,\quad M_3=D-|U-V|.
\]

对 p 个二进小数位的最近值量化，每轴误差最多 \(2^{-(p+1)}\)。严格条件为

\[
2^{p+1}M_1>3D,\qquad
2^{p+1}M_2>3D,\qquad
2^pM_3>D.
\]

当三个 M 都为正，满足该证书的最小非负 p 可以完全用整数运算计算：

```python
p = max(
    (3 * D // (2 * M1)).bit_length(),
    (3 * D // (2 * M2)).bit_length(),
    (D // M3).bit_length(),
)
```

它是严格内部误差盒证书的最小位数，不一定等于某个特定舍入恰好成功所需的最小位数。若任何 M 为零，则正半径误差盒不能严格包含在唯一格内部，接口返回 `None`。这不表示边界点无法有限计算：误差为零时仍按精确 tie 规则判定，特定量化也可能恰好保留该 tie。

### 5.3 没有适用于任意有理变换的统一最低位数

对任意固定 p，可以把点放在离边界更近的位置。例如

\[
(q,r)=\left(\frac12+2^{-60},0\right)
\]

精确归属为 \((1,0)\)。降到 59 个二进小数位会落到边界并被现有 tie 规则分到 \((0,0)\)，60 位则保持原归属。显式有理平移可以产生这种合法近边界情况。

当前 Core 的范围应另行表述：其最终坐标本来是 Q40，第 3.4 节证明上述统一最终坐标降位模型的全域最低固定精度是 40。新有理家族允许任意细的边界残差，因此不存在与输入无关的有限统一位数，也没有受 40 位约束的普遍上界。

### 5.4 “首个通过位数”不是稳定门槛

对点 \((1/3,3/10)\)，精确目标是 \((0,0)\)。实际最终舍入产生：

| p | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 目标格 | (0,0) | (1,0) | (0,0) | (1,0) | (0,0) | (1,0) | (0,0) |

因此不能把第一次通过的 p=0 称作稳定最低精度。该点的严格证书给出 p≥6，所有更高位数都能通过同一证书。扫描结果采用完整已测范围的稳定后缀，并与可证明的裕量条件分开报告。

## 6. 份额、材料和压力的误差预算

### 6.1 每源 96 点份额的离散分辨率

如果某源格有 M 个样本标签改变，则对任意目标 c：

\[
|\Delta a(c)|\le M/96,\qquad
\operatorname{TV}(a,\hat a)\le M/96,
\qquad \|a-\hat a\|_1\le2M/96.
\]

一个净命中变化为 1/96，约 1.0417 个百分点。因此若要求所有目标的份额绝对误差严格小于 1%，当前整数命中直方图就必须完全相同；样本标签仍可能通过交换后抵消。

仅要求目标集合相同可以更宽松，但需要单独检查：原有每个目标至少保留一个命中，且没有样本进入新目标。只控制平均份额误差不足以证明这一点。

### 6.2 计数可以压缩，数值含义仍然精确

每个源格对一个目标的命中数范围是 0–96，共 97 种值，**7 个比特足够编码**；按常用字节存储可使用一个 `uint8`。已知采样总数为 96，就能随时精确恢复 `hit_count/96`，无需为每次覆盖份额保存浮点数。

这只适用于单源格的命中计数。跨来源材料总量和累积支撑可能远超 255，不能一并压成 `uint8`。计数来自原生几何覆盖，编码方式不建立新的对象关系索引。当前诊断代码未改变持久化格式；这是可直接采用的结果表示选择。

### 6.3 压力误差可由支撑误差控制

对于固定需求 D、固定 \(\kappa>0\)：

\[
P(S)=1+99\frac{[D-S]_+}{D+\kappa}
\]

满足

\[
|\Delta P|\le\frac{99}{D+\kappa}|\Delta S|.
\]

若下层源格 d 的材料量为 \(m(d)\)，其中 \(M_d\) 个样本标签改变，则可用

\[
|\Delta S(c)|\le\sum_d m(d)M_d/96
\]

给出保守支撑误差界。实际计算还可以按特定目标的净计数变化收紧。

显示分数使用 half-up，整数是否不变要看精确压力到半整数门槛的距离。**误差小于 0.5 仍可能改变显示结果**，例如 17.49 与 17.51 相差 0.02，却分别显示 17 与 18。若误差区间跨越门槛，应保留精确计算或接受明确的显示差异预算。

## 7. 降低哪一层精度，决定了需要证明什么

本轮降位的是最后目标坐标。若改为参数、矩阵系数、输入样本或每一步算术降位，必须重新计算误差传播。

对一行仿射式 \(aq+br+c\)，如果三个系数各有不超过 \(\varepsilon\) 的误差，而 q/r 视为精确值，则输出误差界为

\[
\varepsilon(|q|+|r|+1).
\]

大坐标会放大系数量化误差。若输入也有误差，还要加上矩阵作用的误差；逆矩阵可能继续放大，接近奇异的矩阵尤其需要单独界定。非线性扭转链应传播可信区间或逐步误差，而不能把最后一次舍入的半 ULP 当成整个链的误差。

固定 p 个小数位表示相对于格距的绝对精度，和 float32/float16 的有效位数不是一回事。浮点绝对误差随坐标数量级改变，世界锚越大，可分辨的小位移越少。计算应尽量在相对坐标和局部残差上进行，同时保留整数格点部分的范围。

完全相同的外层扭转可在精确参数层先消去，再做低精度计算。若分别执行经过舍入的正反扭转，不能凭代数上的 \(W^{-1}W=I\) 假定舍入误差也会消失。

建议的下一执行结构是：以 16 位局部残差起步，产生带可信总误差界的近似点；误差盒能认证时直接取目标格，不能认证时提高精度或执行精确谓词。当前新增模块提供认证环节与诊断探针，尚未将整个非线性执行器替换成这个低精度流程，也未报告其性能收益。

## 8. 连续覆盖的保证仍须单独建立

全部 96 个样本归属保持，能够保持本轮离散覆盖合同。连续边界可能移动而没有任何样本越界，连续相交面积也可能改变而命中数不变。

若所需目标是连续交叠面积误差不超过某值、接触关系不变、或拓扑不变，应增加对应的几何间隙、相交面积上下界或自适应细分条件。不能把本轮有限样本的零差异提升为连续几何的零差异。

## 9. 已实现接口与复现

[precision_budget.py](../../lab/nollm-lab/geometry/precision_budget.py)提供三个简单接口：

```python
quantize_axial_ratio(q_num, r_num, denominator, bits)
# -> (rounded_q_num, rounded_r_num, 2**bits)
# 两坐标分别 half-even，不经 float。

certify_axial_ratio(q_num, r_num, denominator, error_q=0, error_r=None)
# -> (cell_q, cell_r) 或 None
# 精确误差参数支持 int、Fraction、文本；error_r 缺省时等于 error_q。

minimum_safe_fraction_bits(q_num, r_num, denominator)
```

## 10. 方法资料与适用范围

- [Shewchuk：Adaptive Precision Floating-Point Arithmetic and Fast Robust Geometric Predicates](https://www.cs.cmu.edu/~quake/robust.html)：讨论接近判定零点时固定浮点精度可能给出错误符号，以及按需要增加计算工作的自适应精确谓词。其具体 orientation/incircle 算法没有直接替代本文的轴向覆盖判定。
- [CGAL：Filtered_kernel](https://doc.cgal.org/latest/Kernel_23/structCGAL_1_1Filtered__kernel.html)：使用区间过滤获得精确谓词，并明确区分谓词与几何构造的精确性。它支持“先低成本认证、困难点精确处理”的工程方向，不证明本项目任意低精度映射构造已经正确。
- [Nollm 有理数化计算架构](NOLLM_RATIONAL_COMPUTATION_ARCHITECTURE_20261122.md)：现有旋转、扭转、整数编译、覆盖采样及压力合同。
- [Core 覆盖合同](../../packages/nollm-core/src/nollm_core/coverage_contract.py)：当前 96 个样本、单命中关系阈值与地址域。

三面裕量、整数精度公式和压力误差界均由本文给出的表达式推导。常规扫描只证明所列输入的结果；第 3.4 节的全域最低固定精度结论由 Q40 恒等性和全部更低精度的合法反例共同建立，范围限于现行 Core 与指定最终量化模型。本轮未建立新的数论研究任务。
