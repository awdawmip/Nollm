Boundary statement:

HAG1 is a local, file-first, trusted-host explicit admission gateway. The host must submit a deferred candidate, auditable promotion decision, complete growth submission, and complete placement plan. The gateway only routes through the existing HX1/BA1/DA1 public chain for all-member preflight and independent replayable admission.

HAG1 does not discover candidates, generate semantics or geometry, replace raw DreamShard evidence, assemble a field, recall, register OpenClaw/runtime surfaces, use network services, use caches, or use databases.

Final bundle, matrix evidence ref, and SHA-256 are recorded after final code commit and evidence packaging.
