# M0 Superseded Route Index

M0 preserves the following assets for audit, migration, and regression value,
but they are not active architecture or authority for new implementation:

- Evidence/Capture/Admission Core routes from V2.1
- Evidence-first Core routes from V2.2
- pre-M0 `protocol/v2` architecture claims
- GRF handoff and GRF8 checkpoint reports
- OpenClaw Live Integration taskbooks and partial runs
- raw-slice and source-fallback taskbooks

The ownership manifest classifies the individual tracked files. No file in
these groups is deleted by M0. M1 must review dependency and recovery evidence
before extracting or deleting any implementation.
