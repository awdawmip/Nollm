# GRF7R4 Windows Final Closure

GRF7R4 adds independent snapshot restore and compact-evidence integrity closure.
Full raw evidence is verified locally on Windows and is not uploaded. External
review receives the Git bundle, receipt, and compact audit capsule only.

The 10M corpus is a persisted artifact inventory. The 20K global workload is
sampled artifact-backed queries. The 1M workload contains a high proportion of
idempotent retry while retaining the required real mutation minima. This stage
does not claim a production SLA, complete external raw-evidence review, or
Linux/macOS support.
