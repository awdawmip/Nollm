# NOLLM GRF4R Gate C Benchmark Report

Gate C evidence is generated by
`experiments/grf/run_grf4r_reality_benchmark.py`. The runner executes real
capture, place-only, admit-existing-placement, FieldEngine insertion, relation
field build, recall, and source fallback for 100,000, 500,000, and 1,000,000
synthetic evidence records.

Every written Core object is canonical-serialized and counted. Latencies use
`perf_counter_ns`; throughput is calculated from measured items, serialized
bytes, and elapsed time. No metric is manually filled or estimated from a
per-item formula. The validation store retains only active pipeline facts but
serializes every write, keeping memory bounded without replacing Core calls.
