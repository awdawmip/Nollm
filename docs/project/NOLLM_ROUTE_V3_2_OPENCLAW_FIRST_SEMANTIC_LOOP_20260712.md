# Nollm Route V3.2: OpenClaw-First Semantic Loop

V3.1 remains the stable modular architecture and governance baseline. V3.2 is the current semantic implementation route.

The first active semantic loop is normal OpenClaw chat selecting the Nollm Statement Formation tool, followed by canonical prompt construction, a real OpenClaw model call, strict parser validation, and the public Access exact-span contract. Formation does not place or persist statements.

Synthetic Formation corpora are parser/schema regression assets only. They do not establish live semantic quality. Current live validation is gated by `openclaw:formation-live` and requires runtime registration, normal-chat autonomous selection, zero direct tool RPC, lifecycle controls, and read-only evidence verification.

Placement, Recall, Core mutation, Python semantic fallback, and live OpenClaw memory persistence remain outside this route.
