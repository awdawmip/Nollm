# Nollm 研究价值试验与下一步开发任务

日期：2026-11-21。任务类型：内部可信环境中的探索开发和工程评价。用户目的：为进取数论形成大模型可用、能连接公式/定理/条件、能跨研究路线复用的外部记忆，并据真实证据判断是否值得持续投入。后续其他项目可复用同一个内核，项目语义留在薄适配层。

主执行位置：Nollm PR #7。中控台集成继续沿用 em-research-mcp PR #112；Enterprise Math PR #2847 保存项目需要与验收结果。这里不新建研究身份、数学 Task、CLAIM 或新的控制入口。

## 1. 目标和现有边界

交付一个能被真实研究任务使用、能与简单基线公平比较的记忆内核。需要回答三个不同问题：整理后的理解是否有价值；Nollm 原生几何组织增加什么价值；保存和修订能否在后续不同问题上收回形成成本。

当前已经上线的五工具是 `walk / find / show / source / save`。线上接口可用、保存可读回和跨会话读取已有证据；这些工程事实不自动证明科研效率提升。当前 EM 适配器仅开放 new / revision_current、物理 layer 0 和 Coverage/lateral 召回，未充分用到原生跨区连接、移动及统一 Encounter。能力是否在 Core 内存在，与是否已在研究端可用分别记录。

遵守用户要求：**不写防御性代码，不加入无谓的验证、哈希、认证、审计或通用治理框架。** 只实现当前试验需要的业务行为、简单计量及能判断真实结果的检查。普通错误按原任务修复。这里的数学适用条件、来源版本与公平比较是研究正确性和试验输入本身，不是额外安全机制。

沿用 `docs/architecture/NOLLM_FIRST_PRINCIPLES_AND_ANTI_DRIFT_20260711.md`：Host 判断语义并形成/放置理解；Core 执行确定性几何；Access 解析原始证据；每次 recall 一个最终物理入口；Physical Memory Layer 和 Aggregation Order 分开。Flat/graph/vector 可当外部比较臂，不进入原生正确性主路径。科学关联仍需来源和条件，几何邻近不表示逻辑蕴含。

## 3. 三个比较臂

| 臂 | 可用信息和入口 | 可以归因的收益 |
|---|---|---|
| S：直接资料 | 冻结原文，正常标题浏览、词面查找和原文窗口；包括原本存在的跨线研究 | 直接处理资料的实际基线 |
| F：同内容平面记忆 | 与 N 完全相同的理解正文、标题、条件、关系解释、来源和版本；catalogue/find/show/source，可自主改写查询 | F 相对 S：提前整理和复用的收益 |

### 导航修复的具体线索

当前 `coverage_cli.surface` 每次重放全部 choices；`surface_selection` 在没有任何阶满足预算时选最高阶并置 overflow，而 EM 的简化返回未将这一状态带给 Host。已存在的导航状态序列化可用来继续当前页；是否采用由实现者结合当前代码决定。先消除重复工作，保留几何语义，不借此重写 Q40/Coverage 数学核。

每页 8 的消融已经让 128 场的所测目标全部到达，但输出字节增加。它是一个可比较候选，不是已经确认的总体最优默认值。不要只提高限制并把错误消失当成性能问题解决。有关合成选择策略和失败计时的限制见架构诊断原文。

### 连接测试的语义内容

连接理由可以用普通命题保存：在什么对象、观测语言和输入条件下能应用哪个结果，哪些相似情形仍不适用，并附证据。无需引入通用关系数据库、类型本体或额外强制字段表。Host 根据实际研究判断是否形成、修订、连接或暂缓；Core 只执行几何。

FREE A 沿用当前的问题先行精确查询规则：自主形成相关问题后，冻结前仍可读取所需的精确定义、条件和工具。实验隔离完整成果目录与研究建议，不增加一刀切的已有知识禁读。实际已经曝光的材料如实记录，不能通过换会话名称或换记忆入口抹去。更严格的薄基础条件只能是明确标记的比较臂，不升级成一般科研门槛。

## 6. 质量与成本判定

对每题的必要科学义务逐项记 PASS / PARTIAL / FAIL，并保留答案与来源。条件丢失、过时结论覆盖新结果、把编码等同获取、把存在性当可执行方法等错误单列。不同臂都答对时，继续看实际成本和是否支持后续工作，不因篇幅更长加分。

成本按 `形成 + 修订/维护 + 各次查询/原文展开 + 结果核对` 记录。真实 usage 可得时列输入/输出/缓存 token；不可得时只报告可见工具 UTF-8 字节、次数、实际运行时长和未知项。工具字节不是 token，内部函数时间不是模型思考时间，并行总耗时不是每个模型耗时。已有形成工作可以复用，但历史成本不能设零。

不在小样本上声称稳定胜率或统计显著性；开发题可定位错误，价值结论还需未参与 formation 的真实问题。单次失败先查检索、摘要、版本、推理分别在哪个环节，不把一个例子扩成“几何一定无效”或“数学做不到”。

## 7. 继续、转向与停止扩大投入

| 观察结果 | 投入决策 |
|---|---|
| F/N 相对原文有收益，N 与 F 相当或更贵 | 继续做理解形成、条件维护和复用；几何单独承担需要证明的实验目标 |
| 原生连接/放置在新题上使正确跨线复用更好，或同质量下完整成本更低 | 围绕有收益的题型继续优化，再扩展真实材料规模 |
| 优势依赖独有摘要、已知入口或预写答案 | 修正实验；不据此扩大几何主路径投入 |
| 来源更新不可靠、错误迁移增多 | 先修具体语义和生命周期；记录错误连接并撤回 |
| 多个目标任务中 N 持续更贵，且没有连接/维护增益 | 暂停全面替代检索的目标，保留可用的命题与证据资产，缩小几何实验范围 |

这些是工程取舍，不设置凭空的百分比 KPI。小模型后训练的前提是观察到可重复、样本可标注、普通检索/提示修正难以解决的 formation、条件识别或导航错误。先收集真实失败和成功轨迹，再比较专职小模型与现有 Host 在相同接口上的能力和总成本。事实更新和证据版本仍由外部记忆保存。
