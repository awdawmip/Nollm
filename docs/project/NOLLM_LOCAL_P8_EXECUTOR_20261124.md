## 1. 单位、规范锚与完整地址

调用者显式提供正有理 `local_length=ell`，表示源层一个局部格长度在世界单位中的长度。未提供单位时返回明确错误。相似层采用其实际正尺度；一般剪切映射可给出声明单位，不把它当作相似变换或强行求无理平方根。固定实验中的单位从原输入相似矩阵精确提取并核验。

将源、目标仿射写为 `A_i(x)=M_i*x+b_i`，其中 `b_i=A_i(0)`。对本次源格整数地址 `c`：

1. 先删除零强度恒等扭转，再精确消去两侧有序且相同的外层扭转后缀。
2. 规范世界锚取 `O=A_s(c)`，即源格**扭转前的精确仿射位置**。全部96样本共享该锚。
3. 源局部采样偏移 `u` 映到 `(M_s/ell)*u`；剩余扭转中心变为 `(center-O)/ell`，半径平方除以 `ell²`，强度不变。
4. 精确计算 `T=A_t^{-1}(O)`，逐轴分离偶数整数锚 `E=2*floor(T/2)`。目标局部坐标为 `ell*M_t^{-1}*y+(T-E)`。
5. 对局部中间量执行一次 p8 固定精度递推，按原半偶舍入和 cube tie 分类，再恢复完整整数锚 `E`。

矩阵系数及完整整数地址在舍入前精确参与计算，不把系数先截成8位再乘大地址。每点的扭转递推复用既有定点标量核；新实现更换的是单位、锚及地址分离方式。纯仿射继续使用已有精确公共分母整数核。

### 为什么换表示不再改变标签

`reanchor()` 保持 `M_i` 与 `b_i=A_i(0)`，所以上述规范量保持不变。对共同世界变换 `x -> lambda*x+d`，同时令 `ell -> lambda*ell`，源规范矩阵、所有相对中心、归一化半径和目标局部映射也逐项不变。相同规范系数、相同96采样偏移执行同一舍入递推，得到相同标签。

这里限定于现有有序映射合同中的表示重锚、正共同尺度与共同平移。真实移动、改扭转中心或改变层间相对几何仍可改变关系。

### 独立复算及实际发现的缺陷

独立 Fraction 参考实现自行规范化、逐步舍入并做最终绝对坐标分类；双方向、4种位数、3源格、96点共2,304次逐点坐标比较通过。另覆盖剪切、超大整数、负坐标和边界 tie。低层整数核的 `2**90/2**120` 地址探针验证整数分离；公共 GeometryAddress 继续执行原存储域。

审查发现“先消去共同后缀、后过滤零强度”会使一个恒等操作挡住应消去的共同扭转。保存的反例在源格 `(1,1)` 改变3个标签、`(2,-1)` 改变1个标签。回归先运行失败，再将零强度过滤移到后缀消去之前，全部通过。

```python
coverage = sampled_rational_coverage(
    source_cell, target_layer, source_map, target_map,
    mode="local_quantized", local_length="5/4",  # 源层实际格长
)
```

覆盖输出包含合同名、`fractional_bits=8`、精确单位、`anchor_policy=source_cell_affine_center` 和 `target_anchor_policy=even_integer`。
`evaluate_rational_pressure` 的单位属于 lower/source 层；`compare_rational_pressure` 可分别指定 `local_length` 与 `after_local_length`，后者默认沿用前者。缺失需求继续保持未知；测试中 `10**60+18` 单位材料完整守恒。
