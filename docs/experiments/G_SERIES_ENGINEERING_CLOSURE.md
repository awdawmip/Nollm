# G-Series Engineering Closure

G0-G8 completed the internal engineering track for true-tiling geometry,
parameter profiles, multi-step coverage, offset sampling, reverse-cover MILP,
Gravity Report V1, Mode 3 free-drift traces, and a minimal ablation scaffold.

What is now experimentally testable: whether gravity reports make drift risk,
lateral discovery, semantic breaks, and return-route visibility easier to
compare than retrieval-only candidates.

What is still not implemented: stable recall APIs, public tool surface
expansion, real LLM judging, automatic writeback, automatic card creation,
automatic anchor creation, trust/status mapping from drift, and production
multi-chart gluing.

G-series proves that Nollm's engineering hypothesis can now be tested, not that
the hypothesis is true.

The next engineering decision point is whether deterministic and real-LLM
ablations show enough visibility gain to justify turning selected experiments
into product-facing protocol work.
