# E5 Real Corpus Dream Dry-Run

E5 is an internal dry-run experiment.

It uses a bounded set of real Nollm repository Markdown documents to exercise
the Dream Geometry record stack with realistic text shapes.

E5 does not write cards, confirm placement, create anchors, or change the
stable recall/tool surface.

The dry-run exists to expose integration issues before any production placement
or recall behavior is considered.

Run from `reference/python`:

```bash
python scripts/run_real_corpus_dream_dry_run.py
```

Generated artifact:

```text
examples/openclaw_dream/real_corpus_dry_run_report.json
```
