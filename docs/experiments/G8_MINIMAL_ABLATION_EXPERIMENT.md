# G8 Minimal Ablation Experiment

G8 is an internal deterministic ablation scaffold. It is not evidence from a
real LLM yet and does not create a stable recall product or public tool
surface.

The fixture supplies external retrieval candidates. Nollm renders visibility
conditions N0-N5 and uses a deterministic proxy evaluator to measure whether
drift risk, semantic breaks, useful lateral discovery, geometry marks, gravity
reports, and a return-vector placeholder are visible.

Gravity reports annotate drift; they do not reject candidates. The experiment
does not write cards, create anchors, persist memory, or map drift classes to
trust/status.

The next real experiment would replace the deterministic proxy with actual LLM
judging while keeping the same report shape for comparison.
