# Dream Geometry Internal Runners

The Dream Geometry runners are internal experiment and regression tools.

They are not stable recall, placement, card-writing, or tool-surface features.

## E9 Failure Triage

E9 converts existing internal Dream Geometry JSON reports into deterministic
human-readable triage Markdown.

It is diagnostic only. It does not write cards, confirm placements, create
anchors, or enter the stable recall/tool surface.
