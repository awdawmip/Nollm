# E3 Adversarial Dream Regression Pack

E3 is adversarial regression infrastructure for Dream Geometry experiments.

It is not stable recall, not placement confirmation, and not a production
placement system.

The regression pack deliberately exercises malformed and boundary-violating
records so future changes fail loudly when they drift toward tree, folder, or
anchor-ownership semantics.

It rejects parent/children, folder, and anchor-ownership regressions while
keeping Dream Geometry experimental until real runs expose enough behavior.
