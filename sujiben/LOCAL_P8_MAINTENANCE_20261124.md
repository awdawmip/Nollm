## 独立后继 Host 的实际试用

另一独立读者在未预先获得目标表达ID或物理地址的情况下，依据首屏实际短判断选入口。它共执行五次原生 `encounter`，两次下降均使用刚显示的候选，实际路径为：

`L−2(0,−3) → L−1(−1,−3) → L0(−3,−3)`

读者以 `--recall nollm.quantized-structure.v3` 结束，预算未耗尽。从这一入口的正文中回答了四个问题：

1. 局部 p8 已完成到哪里：显式 Lab 合同、覆盖、支撑压力、候选比较和 CLI 已实现。
2. 单位如何指定：正有理 `local_length` 表示源层局部格长，世界单位共同缩放时同步缩放。
3. 当前速记本使用什么引擎：Core Q40／96；旧量化默认 p12；adaptive 仍保持原有理采样标签。
4. 接受哪些数值变化：局部固定精度可以改变采样归属、关系、份额、显示压力及候选排序；压力继续供 Host 参考。

简洁回读保留一个来源窗口及 `source_count=2`。读者对已经遇到的准确ID执行 `show`，展开两条来源，再通过 GitHub connector 回读上述固定提交中报告的第1–126行；返回 blob 为 `f9a8ef85855535d68e9fcfd29c74027a9ecf5747`。来源原文补齐了具体实现名和接口单位细节，与判断正文一致。

该读者没有用项目词搜、全 Statement 扫描、源码扫描或预给地址寻找目标，也没有改动工作场。它未重跑实现测试。本记录将结果限定为本次单入口后继 Host 可用性试用；没有额外模型对照或海量吞吐结论。
