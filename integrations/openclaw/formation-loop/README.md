# Nollm OpenClaw Formation Loop

This adapter provides durable Capture, background Writer v3 and Cartography,
and same-run main-agent single-entry geometric Recall through public
`nollm-access` APIs.

The active Writer emits exact Evidence quotes. Access resolves codepoint spans,
persists canonical Statement provenance, and rejects stale Cartography plans
before writes. Legacy Writer parsing is available only through the explicit
offline migration function.

The registered `nollm_memory` tool accepts only an action, operation/region/entry
IDs, and a fixed budget option. Physical coordinates remain internal. Default
Locality is geometry-ranked and bounded to four Statements or 3000 characters;
one expansion may increase the same selected entry to eight Statements or 6000
characters. The active user Recall path starts no independent Reader child.

Capture and Pending read-your-writes remain local, bounded, and fail-open.
Formation and Cartography remain background operations. Core is not imported by
the TypeScript plugin and no Topic, entity, vector, graph, embedding, query, or
fact index is introduced.
